# Pulse Website

Official landing page for [Pulse](https://github.com/Regncreative/Pulse) — a modern, read-only Windows diagnostics platform.

Live: [pulse.regncreative.com](https://pulse.regncreative.com)

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Notes

- Release download buttons use GitHub Releases when an installer asset is published; until then CTAs point to the GitHub repo.
- Branding assets live in `public/brand/` (Pulse Telemetry Peak mark).
